Section A · The Identity (x + a)(x + b)⏱ 25 min
HOW TO SOLVE
  • (x + a)(x + b) = x² + (a + b)x + ab.
  • Watch the signs: (x − 3)(x + 5) uses a = −3, b = 5.
WORKED EXAMPLE
Expand (x + 4)(x − 7).
→ a + b = 4 − 7 = −3, ab = −28.
→ x² − 3x − 28.

  3. A3(p + 8)(p − 3)
  4. A4(2m + 1)(2m + 5)
  5. A5(3x − 2)(3x + 7)
Section B · Area Models⏱ 20 min
HOW TO SOLVE
  • A rectangle of sides (a + b) and (c + d) splits into four smaller rectangles: ac, ad, bc, bd.
  • Add the four areas to get the product.
WORKED EXAMPLE
Use an area model for (x + 3)(x + 2).
→ Parts: x·x = x², x·2 = 2x, 3·x = 3x, 3·2 = 6.
→ Total: x² + 5x + 6.
  1. B1Draw an area model and find (x + 5)(x + 1).
  2. B2A square garden of side a m has its side increased by 3 m. By how much does the area increase?
  3. B3A rectangle is (2x + 3) cm by (x + 4) cm. Find its area.
  4. B4A square of side (y − 2) cm is cut from a square of side y cm. Find the area left.
Section C · Smart Calculation⏱ 25 min
HOW TO SOLVE
  • (a + b)(a − b) = a² − b²; (a ± b)² = a² ± 2ab + b²; (x + a)(x + b) = x² + (a + b)x + ab.
  • Squares of numbers ending in 5: (10n + 5)² = 100n(n + 1) + 25.
WORKED EXAMPLE
Find 104 × 106 and 65².
→ 104 × 106 = (100 + 4)(100 + 6) = 10000 + 1000 + 24 = 11024.
→ 65² = 100 × 6 × 7 + 25 = 4225.

Section D · Simplify and Evaluate⏱ 30 min
HOW TO SOLVE
  • Expand each product, then collect like terms.
  • Substitute values only after simplifying.
WORKED EXAMPLE
Simplify (x + 2)² − (x − 2)(x + 2).
→ x² + 4x + 4 − (x² − 4).
→ = 4x + 8.
  1. D1Simplify (a + 5)(a − 2) − (a + 3)(a − 3)
  2. D2Simplify (2x + 3y)² + (2x − 3y)²
  3. D3Find the value of x² + 6x + 9 when x = 47.
  4. D4If a − b = 4 and ab = 21, find a² + b².
