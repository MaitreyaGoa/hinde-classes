Section A · Frequency Tables⏱ 25 min
HOW TO SOLVE
  • Raw data → frequency table: count how many times each value (or class) occurs.
  • Class interval 10–20 includes 10 but not 20. Class mark = (lower + upper) ÷ 2. Class size = upper − lower.
WORKED EXAMPLE
Find the class mark and class size of 20–30.
→ Class mark = (20 + 30) ÷ 2 = 25.
→ Class size = 30 − 20 = 10.
  1. A1Marks of 20 students: 5, 8, 6, 7, 5, 9, 8, 6, 5, 7, 8, 9, 10, 6, 5, 7, 8, 6, 9, 5. Make a frequency table.
  2. A2Find the class marks of 0–10, 10–20, 20–30, 30–40.
  3. A3The class marks of a distribution are 15, 25, 35, 45. Find the class size and the classes.
  4. A4Weights (kg): 38, 42, 45, 51, 36, 48, 44, 40, 53, 47, 39, 46. Make a grouped table with classes 35–40, 40–45, 45–50, 50–55.
Section B · Bar Graphs and Histograms⏱ 30 min
HOW TO SOLVE
  • Bar graph: separate bars of equal width for categories.
  • Histogram: bars touch, one bar per class; height = frequency (when class sizes are equal).
  • Use graph paper and choose a clear scale.
WORKED EXAMPLE
Draw a bar graph: favourite fruit – Mango 12, Banana 8, Apple 6, Grapes 4.
→ x-axis: fruits, y-axis: number of students (1 cm = 2 students).
→ Draw 4 separate bars of heights 6, 4, 3, 2 cm.
  1. B1Draw a bar graph: students in Classes 6–10 are 40, 35, 45, 30, 50.
  2. B2Draw a histogram for: 0–10: 4, 10–20: 9, 20–30: 12, 30–40: 7, 40–50: 3.
  3. B3From the table in Q2, how many values are less than 30?
  4. B4What is the main difference between a bar graph and a histogram?
Section C · Frequency Polygon⏱ 25 min
HOW TO SOLVE
  • Plot (class mark, frequency) for each class and join with straight lines.
  • Add a class of frequency 0 at each end so the polygon starts and ends on the x-axis.
WORKED EXAMPLE
Which points would you plot for 10–20: 5 and 20–30: 8?
→ Class marks 15 and 25.
→ Plot (15, 5) and (25, 8).
  1. C1Write the points to plot for: 0–10: 4, 10–20: 9, 20–30: 12, 30–40: 7, 40–50: 3 (include end points).
  2. C2Draw the frequency polygon for the table in Q1 on graph paper.
  3. C3From your polygon, which class has the highest frequency?
Section D · Mean of Data (Revision)⏱ 40 min
HOW TO SOLVE
  • Mean = (sum of all values) ÷ (number of values).
  • For a frequency table: mean = Σ(value × frequency) ÷ Σfrequency.
WORKED EXAMPLE
Find the mean of 4, 7, 9, 10, 15.
→ Sum = 45, count = 5.
→ Mean = 9.
  1. D1Find the mean of 12, 15, 18, 20, 25, 30.
  2. D2The mean of 5 numbers is 18. One number is removed and the mean becomes 16. Find the removed number.
  3. D3Find the mean marks: marks 5, 6, 7, 8, 9, 10 with frequencies 5, 4, 3, 4, 3, 1.
  4. D4The mean of 10, 12, 15, x and 18 is 14. Find x.
  5. D5The mean weight of 6 boys is 42 kg and of 4 girls is 37 kg. Find the mean weight of all 10.
