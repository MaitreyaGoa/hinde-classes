Section A · Particular Terms⏱ 25 min
HOW TO SOLVE
  • aₙ = a + (n − 1)d. To find n, solve aₙ = given value; n must be a natural number.
  • Number of terms from a to l: n = l − ad + 1.
WORKED EXAMPLE
The AP 3, 8, 13, …, 253 has how many terms? Find its middle term.
→ n = 2505 + 1 = 51.
→ Middle = 26th term = 3 + 25 × 5 = 128.
  1. A1Find the 12th term of 3, 8, 13, …
  2. A2Which term of 21, 18, 15, … is −81?
  3. A3Is 0 a term of 31, 28, 25, …?
  4. A4How many three-digit numbers are divisible by 7?
  5. A5How many terms are there in 7, 13, 19, …, 205?
Section B · Finding the AP from Conditions⏱ 25 min
HOW TO SOLVE
  • Write each condition as a + (n − 1)d = value; solve the two equations for a and d.
  • a, b, c are in AP when 2b = a + c.
WORKED EXAMPLE
The 3rd term is 12 and the 50th term is 106. Find the 29th term.
→ a + 2d = 12, a + 49d = 106 → d = 2, a = 8.
→ a₂₉ = 8 + 56 = 64.
  1. B1The 5th term is 19 and the 12th term is 47. Find the AP.
  2. B2a₄ + a₈ = 24 and a₆ + a₁₀ = 44. Find the first three terms.
  3. B3For what n are the nth terms of 63, 65, 67, … and 3, 10, 17, … equal?
  4. B4Find k if 2k + 1, 3k + 3, 5k − 1 are in AP.
Section C · Sums⏱ 35 min
HOW TO SOLVE
  • Sₙ = n2[2a + (n − 1)d] or Sₙ = n2(a + l).
WORKED EXAMPLE
Find the sum of the first 15 multiples of 8.
→ a = 8, l = 120.
→ S = 152(128) = 960.
  1. C134 + 32 + 30 + … + 10
  2. C2a = 5, d = 3, aₙ = 50. Find n and Sₙ.
  3. C3Find the sum of all odd numbers between 0 and 100.
  4. C4Find the sum of the first 1,000 positive integers.
  5. C5a = 5, l = 45 and Sₙ = 400. Find n and d.
Section D · Word Problems⏱ 35 min
HOW TO SOLVE
  • Identify a, d and n from the story.
WORKED EXAMPLE
A hall has 20 seats in the first row and 2 more in each next row. How many seats in 15 rows?
→ a = 20, d = 2, n = 15.
→ S = 152(40 + 28) = 510.
