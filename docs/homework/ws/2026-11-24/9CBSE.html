Section A · Quadrants and Axes⏱ 10 min
HOW TO SOLVE
  • Point (x, y): x = abscissa (left/right), y = ordinate (up/down).
  • Quadrant signs: I (+, +), II (−, +), III (−, −), IV (+, −).
  • If y = 0 the point is on the x-axis; if x = 0 it is on the y-axis.
WORKED EXAMPLE
Where does (−6, 2) lie?
→ x negative, y positive → Quadrant II.
  1. A1(3, −5)
  2. A2(−2, 7)
  3. A3(−4, −1)
  4. A4(0, 6)
  5. A5(−8, 0)
  6. A6(5, 5)
Section B · Plotting and Reading Points⏱ 20 min
HOW TO SOLVE
  • Use graph paper. Draw the axes, mark the origin O and use 1 cm = 1 unit.
  • To plot (a, b): move a units along x (right if +, left if −), then b units up/down.
WORKED EXAMPLE
Plot P(−3, 4).
→ From O go 3 units LEFT, then 4 units UP. Mark P.
  1. B1Plot A(2, 3), B(−3, 2), C(−2, −4), D(4, −1) on graph paper.
  2. B2Write the abscissa and ordinate of (−7, 4).
  3. B3Write the coordinates of the point on the x-axis 5 units to the left of the origin.
  4. B4Plot (1, 1), (5, 1), (5, 4), (1, 4) and join them in order. Name the figure and find its area.
Section C · Writing ax + by + c = 0⏱ 15 min
HOW TO SOLVE
  • Bring every term to the LHS so that RHS = 0.
  • Read a (coefficient of x), b (coefficient of y), c (constant). A missing term has coefficient 0.
WORKED EXAMPLE
Write 3x = 2y − 5 in the form ax + by + c = 0.
→ 3x − 2y + 5 = 0, so a = 3, b = −2, c = 5.
  1. C12x + 3y = 9
  2. C2x = 4y
  3. C3y = 5
  4. C4The cost of a notebook (₹x) is twice the cost of a pen (₹y). Write as a linear equation.
Section D · Solutions of a Linear Equation⏱ 20 min
HOW TO SOLVE
  • (p, q) is a solution if putting x = p and y = q makes LHS = RHS.
  • To find solutions: choose any value of x, put it in, and find y.
  • A linear equation in two variables has infinitely many solutions.
WORKED EXAMPLE
Is (1, 3) a solution of 2x + y = 5?
→ 2(1) + 3 = 5 = RHS. Yes.
  1. D1Is (2, 1) a solution of x + 2y = 4?
  2. D2Is (3, −1) a solution of 2x + 5y = 1?
  3. D3Is (1, 2) a solution of 3x − y = 2?
  4. D4Find k if x = 2, y = 1 is a solution of 2x + 3y = k.
  5. D5Write any four solutions of x + y = 6.
  6. D6Find a if (a, 3) lies on the line 2x − y = 5.
Section E · Graphs of Linear Equations⏱ 25 min
HOW TO SOLVE
  • Make a table of at least 3 points (x = 0 and y = 0 are easiest).
  • Plot the points on graph paper and join them with a straight line; extend both ends.
  • The line cuts the x-axis where y = 0 and the y-axis where x = 0.
WORKED EXAMPLE
Draw x + 2y = 4.
→ x = 0 → y = 2; y = 0 → x = 4; x = 2 → y = 1.
→ Plot (0, 2), (4, 0), (2, 1) and join.
  1. E1Draw the graph of x + y = 4.
  2. E2Draw the graph of y = 2x. Through which special point does it pass?
  3. E3Draw the graph of 2x + y = 6. Where does it cut the axes?
  4. E4Taxi fare: ₹20 for the first km and ₹10 for each further km. Taking distance = x km and fare = ₹y, write the equation. Find the fare for 5 km.
