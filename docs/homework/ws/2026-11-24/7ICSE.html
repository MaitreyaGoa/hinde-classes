Section A · Checking Solutions and Forming Equations⏱ 15 min
HOW TO SOLVE
  • To check a solution: put the value in place of the letter. If LHS = RHS, it is a solution.
  • To form an equation: let the unknown number be x and translate words into symbols ('twice' = 2x, 'added to' = +, 'is/gives' = '=').
WORKED EXAMPLE
Is x = 4 a solution of 3x − 2 = 10?
→ LHS = 3(4) − 2 = 12 − 2 = 10.
→ RHS = 10. LHS = RHS, so YES.
  1. A1Is x = 3 a solution of 2x + 5 = 11?
  2. A2Is y = −2 a solution of 3y − 4 = 2?
  3. A3Write as an equation: '5 added to twice a number gives 17'.
  4. A4Write as an equation: 'A number divided by 4, minus 3, is 2'.
Section B · One-step and Two-step Equations⏱ 25 min
HOW TO SOLVE
  • Goal: get the letter alone on one side.
  • Do the opposite operation on BOTH sides: + ↔ −, × ↔ ÷.
  • Remove the number added/subtracted first, then the number multiplying/dividing.
  • Check your answer by putting it back.
WORKED EXAMPLE
Solve 4x − 7 = 21.
→ Add 7 to both sides: 4x = 28.
→ Divide both sides by 4: x = 7.
→ Check: 4(7) − 7 = 21 ✓

Section C · Letters on Both Sides and Brackets⏱ 25 min
HOW TO SOLVE
  • Open brackets first (multiply the outside number with each term inside; watch the signs).
  • Bring all letter-terms to one side and all numbers to the other side (change sign when you shift).
  • Simplify and divide.
WORKED EXAMPLE
Solve 3(x + 2) = x + 14.
→ Open bracket: 3x + 6 = x + 14.
→ Shift: 3x − x = 14 − 6 → 2x = 8.
→ x = 4.

Section D · Equations with Fractions⏱ 20 min
HOW TO SOLVE
  • Find the LCM of all the denominators.
  • Multiply EVERY term on both sides by the LCM – the fractions disappear.
  • Now solve like a normal equation.
WORKED EXAMPLE
Solve x2 + x3 = 10.
→ LCM = 6. Multiply every term by 6: 3x + 2x = 60.
→ 5x = 60, so x = 12.
  1. D1x3 + x4 = 14
  2. D2x − 25 = 3
  3. D32x + 13 = x + 42
  4. D4x2 − 14 = x3 + 12
Section E · Word Problems⏱ 35 min
HOW TO SOLVE
  • Let the unknown be x. Write what x stands for.
  • Write the other quantities in terms of x.
  • Form the equation from the statement, solve it, and answer the question in words.
WORKED EXAMPLE
The sum of a number and 3 times itself is 48. Find the number.
→ Let the number be x. Then x + 3x = 48.
→ 4x = 48, x = 12.
→ The number is 12.
