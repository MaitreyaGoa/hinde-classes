Section A · Is it a Quadratic Equation?⏱ 15 min
HOW TO SOLVE
  • Simplify both sides fully and bring everything to one side.
  • If the highest power of x is exactly 2 (ax² + bx + c = 0, a ≠ 0), it is quadratic.
  • To check a root: substitute; if LHS = 0, it is a root.
WORKED EXAMPLE
Is x(x + 2) = x² + 5 quadratic?
→ x² + 2x = x² + 5 → 2x − 5 = 0. Highest power 1 → NOT quadratic.
  1. A1(x + 1)² = 2(x − 3)
  2. A2x(x + 1) + 8 = (x + 2)(x − 2)
  3. A3(x − 2)(x + 1) = (x − 1)(x + 3)
  4. A4x³ − 4x² − x + 1 = (x − 2)³
  5. A5Is x = 3 a root of x² − 5x + 6 = 0?
Section B · Solving by Factorisation⏱ 30 min
HOW TO SOLVE
  • Write in the form ax² + bx + c = 0.
  • Find two numbers whose PRODUCT = a × c and SUM = b. Split the middle term.
  • Group, take common factors, and set each factor = 0.
WORKED EXAMPLE
Solve 2x² − 5x + 3 = 0.
→ a × c = 6; numbers −2 and −3 (product 6, sum −5).
→ 2x² − 2x − 3x + 3 = 0 → 2x(x − 1) − 3(x − 1) = 0 → (2x − 3)(x − 1) = 0.
→ x = 32 or x = 1.
  1. B1x² − 3x − 10 = 0
  2. B2x² + 7x + 12 = 0
  3. B32x² + x − 6 = 0
  4. B46x² − x − 2 = 0
  5. B5x² − 16 = 0
  6. B62x² − 7x + 3 = 0
  7. B7100x² − 20x + 1 = 0

Section C · Quadratic Formula⏱ 25 min
HOW TO SOLVE
  • For ax² + bx + c = 0: x = (−b ± √(b² − 4ac))2a.
  • First write a, b, c with their signs. Then find D = b² − 4ac.
  • Simplify the square root where possible.
WORKED EXAMPLE
Solve x² − 2x − 4 = 0.
→ a = 1, b = −2, c = −4. D = 4 + 16 = 20, √20 = 2√5.
→ x = 2 ± 2√52 = 1 ± √5.
  1. C1x² − 4x + 1 = 0
  2. C22x² − 5x + 2 = 0
  3. C3x² + x − 1 = 0
  4. C43x² − 5x + 1 = 0
  5. C52x² + 3x − 2 = 0
Section D · Nature of Roots (Discriminant)⏱ 20 min
HOW TO SOLVE
  • D = b² − 4ac.
  • D > 0: two distinct real roots. D = 0: two equal real roots. D < 0: no real roots.
  • For 'equal roots', put D = 0 and solve for k.
WORKED EXAMPLE
Find k if x² + kx + 9 = 0 has equal roots.
→ D = k² − 36 = 0 → k = ±6.
  1. D12x² − 3x + 5 = 0
  2. D2x² − 6x + 9 = 0
  3. D32x² − 6x + 3 = 0
  4. D43x² − 4√3x + 4 = 0
  5. D5Find k if 2x² + kx + 3 = 0 has equal roots.
  6. D6Find k if kx(x − 2) + 6 = 0 has equal roots.
Section E · Word Problems⏱ 30 min
HOW TO SOLVE
  • Let the unknown be x and form the equation from the statement.
  • Bring it to ax² + bx + c = 0 and solve.
  • Reject answers that don't make sense (negative length, age, speed).
WORKED EXAMPLE
The product of two consecutive positive integers is 132. Find them.
→ x(x + 1) = 132 → x² + x − 132 = 0 → (x + 12)(x − 11) = 0.
→ x = 11 (reject −12). Integers: 11 and 12.
