Section A · Distributive Property⏱ 15 min
HOW TO SOLVE
  • a(b + c) = ab + ac. Multiply the outside term with EVERY term inside.
  • Sign rules: (+)(+) = +, (−)(−) = +, (+)(−) = −.
  • Powers: x × x = x², x² × x = x³.
WORKED EXAMPLE
Expand −2x(3x − 5).
→ −2x × 3x = −6x².
→ −2x × (−5) = +10x.
→ Answer: −6x² + 10x.
  1. A13(2x + 5)
  2. A2−4(a − 3b)
  3. A32x(3x − 7)
  4. A45p(p + 2q − 1)
  5. A5−3m(2m² − m + 4)
Section B · Binomial × Binomial⏱ 25 min
HOW TO SOLVE
  • (a + b)(c + d) = ac + ad + bc + bd. Each term of the first bracket multiplies each term of the second.
  • Then combine like terms (terms with the same letters and powers).
WORKED EXAMPLE
Expand (x + 2)(x − 5).
→ x·x + x·(−5) + 2·x + 2·(−5) = x² − 5x + 2x − 10.
→ = x² − 3x − 10.
  1. B1(x + 3)(x + 5)
  2. B2(a − 4)(a + 6)
  3. B3(2y + 1)(y − 3)
  4. B4(3m − 2)(2m − 5)
  5. B5(p + q)(2p − 3q)
  6. B6(x + 2)(x² − x + 1)
Section C · Using the Standard Identities⏱ 30 min
HOW TO SOLVE
  • (a + b)² = a² + 2ab + b²
  • (a − b)² = a² − 2ab + b²
  • (a + b)(a − b) = a² − b²
  • Identify what 'a' and 'b' are, then substitute. Square the WHOLE term: (3p)² = 9p².
WORKED EXAMPLE
Expand (2x − 3y)².
→ a = 2x, b = 3y.
→ a² = 4x², 2ab = 2(2x)(3y) = 12xy, b² = 9y².
→ Answer: 4x² − 12xy + 9y².
  1. C1(x + 4)²
  2. C2(2a + 3)²
  3. C3(y − 5)²
  4. C4(3p − 2q)²
  5. C5(m + 7)(m − 7)
  6. C6(4x + 5y)(4x − 5y)
  7. C7(x + 12)²
  8. C8(a + b)² − (a − b)²
Section D · Quick Calculation with Identities⏱ 25 min
HOW TO SOLVE
  • Break the number near a round number: 103 = 100 + 3, 98 = 100 − 2.
  • Use (a ± b)² for squares, and (a + b)(a − b) = a² − b² for products like 102 × 98.
WORKED EXAMPLE
Find 99² and 105 × 95.
→ 99² = (100 − 1)² = 10000 − 200 + 1 = 9801.
→ 105 × 95 = (100 + 5)(100 − 5) = 10000 − 25 = 9975.
  1. D1103²
  2. D298²
  3. D351²
  4. D4102 × 98
  5. D547 × 53
  6. D61005²
Section E · Apply the Identities⏱ 25 min
HOW TO SOLVE
  • Use a² + b² = (a + b)² − 2ab and a² + b² = (a − b)² + 2ab.
  • For x + 1x: square both sides; the middle term 2 · x · 1x = 2.
WORKED EXAMPLE
If a + b = 7 and ab = 10, find a² + b².
→ a² + b² = (a + b)² − 2ab = 49 − 20 = 29.
  1. E1If a + b = 9 and ab = 20, find a² + b².
  2. E2If x − y = 3 and xy = 10, find x² + y².
