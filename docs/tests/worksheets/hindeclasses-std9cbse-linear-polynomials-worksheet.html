Part A  ·  Concept Notes

1 Algebraic Expressions — Terms, Variables, Coefficients, Constants

An algebraic expression is formed using numbers, variables (letter-numbers) and the operations of addition, subtraction, multiplication and division. Each part of the expression that is added or subtracted is called a term. In a term, the number multiplying the variable is its coefficient, and a term with no variable is called a constant.

4coefficient of xxvariable + 5coefficient of yyvariable + 3constant term

Here, 4x, 5y and 3 are the three terms of the expression. Note that this expression involves two variables, x and y.

📝 Remember

An expression involving only one variable (like x, y or z alone) is called a univariate (one-variable) polynomial. In this chapter, we study only such one-variable polynomials — for example, 4x, x² + 1, 5y³ + y² + 2y − 1, and 3z + 7 all qualify, but an expression like 4x + 5y + 3 (with two variables) does not.

2 Polynomials in One Variable & Degree

The highest power of the variable appearing in a one-variable polynomial is called its degree. Polynomials are named according to their degree:

DegreeNameGeneral formExample
0Constant polynomialk (a fixed number)8 (= 8x⁰)
1Linear polynomialax + b (a ≠ 0)3z + 7
2Quadratic polynomialax² + bx + cx² + 5x + 1
3Cubic polynomialax³ + bx² + cx + d5y³ + y² + 2y − 1

In the polynomial 5y³ + y² + 2y − 1: the coefficient of y³ is 5, of y² is 1, of y is 2, and the constant term is −1. Its degree is 3, so it is a cubic polynomial.

3 Linear Polynomials & Linear Equations

A polynomial of degree 1 is a linear polynomial, always written in the form ax + b, where a ≠ 0. When a linear polynomial is equated to a fixed number, we get a linear equation — for example, 2x + 10 = 64 is a linear equation formed from the linear polynomial 2x + 10.

Worked Example

The sum of two numbers is 64. One number is 10 more than the other. Find the numbers.

Let the smaller number be x. The larger number is x + 10.
Since their sum is 64: x + (x + 10) = 64 ⇒ 2x + 10 = 64 ⇒ 2x = 54 ⇒ x = 27.

Answer: The numbers are 27 and 37.

4 Evaluating a Polynomial — the Function Machine

A polynomial can be thought of as an input–output process: for every value we put in for the variable (input), the polynomial gives a corresponding value (output). This process is called a function.

5 Linear Patterns

A linear pattern is a sequence of numbers in which the difference between consecutive terms is constant. If the nth term of such a pattern is a linear expression in n (say, dn + c), the pattern increases (or decreases) by the fixed amount d every time n increases by 1.

🔑 Key Idea

To check if a sequence is linear, subtract each term from the next. If the difference is the same number every time, the pattern is linear, and its nth term has the form dn + c, where d is that constant (common) difference.

6 Linear Growth and Linear Decay

Linear expressions are often used to model real situations where a quantity increases or decreases steadily:

  • Linear growth — the quantity increases by a constant amount over equal intervals. Example: C(d) = 100 + 60d (cost increases by ₹60 for every extra km).
  • Linear decay — the quantity decreases by a constant amount over equal intervals. Example: h(t) = 3 − 0.5t (water height falls by 0.5 m every month).

7 Linear Relationships: y = ax + b

A linear relationship between two variables x and y is written as y = ax + b. If we know the values of y for two different values of x, we can find a and b by solving the resulting pair of equations.

Worked Example

A gym charges a fixed monthly fee plus an hourly rate for the badminton court. A student who used the court for 6 hours was billed ₹350, and one who used it for 10 hours was billed ₹470. Find the linear relationship y = ax + b.

When x = 6, y = 350: 350 = 6a + b   ...(i)
When x = 10, y = 470: 470 = 10a + b   ...(ii)
Subtracting (i) from (ii): 120 = 4a ⇒ a = 30.
Substituting in (i): 350 = 6(30) + b = 180 + b ⇒ b = 170.

Answer: y = 30x + 170 (fixed fee ₹170, plus ₹30 per hour).

8 Visualising Linear Relationships (Graphs)

Every linear equation y = ax + b represents a straight line. To draw it, plot any two points that satisfy the equation and join them with a ruler, extending the line in both directions.

⭐ Formula & Quick-Reference Sheet

  • General linear polynomial: ax + b (a ≠ 0); degree = 1.
  • Degree naming: 0 → constant, 1 → linear, 2 → quadratic, 3 → cubic.
  • Linear pattern: common difference d is constant; nth term = dn + c.
  • Linear relationship: y = ax + b, where a = slope and b = y-intercept.
  • Finding a & b from two points (x₁,y₁), (x₂,y₂):   a = (y₂ − y₁) / (x₂ − x₁);   b = y₁ − a·x₁
  • Linear growth ⇒ slope a is positive. Linear decay ⇒ slope a is negative.
  • Lines with the same slope, different intercept are parallel.
  • Every line y = ax + b cuts the y-axis at the point (0, b).
